# Documents publiés

- `projets/` : rapports, diaporamas (exportés en PDF), posters, photos des projets d'élèves.
- `ressources/` : supports de cours, fiches de synthèse, exercices.

Noms de fichiers simples : minuscules, sans espace ni accent (`rapport-vanne-2027.pdf`).

Tout fichier déposé ici est **public**. Pour les travaux d'élèves, voir `docs/CONFIDENTIALITE-ET-DROITS.md` avant tout dépôt.

`projets/exemple-document.pdf` est un document fictif de démonstration : le supprimer avec les fiches d'exemple.
