# Installer le portail sur la tablette Samsung Galaxy

Durée : 5 minutes. Navigateur conseillé : **Google Chrome** (Samsung Internet fonctionne aussi, mais les tests ont été faits pour Chrome).

## 1. Préparer la tablette

1. Connecter la tablette au Wi-Fi.
2. Vérifier que Chrome est à jour (Play Store › Chrome › Mettre à jour).
3. Réglages conseillés pour la classe et la démonstration :
   - **Rotation automatique** activée (le portail s'adapte en paysage et en portrait) ;
   - **Taille de police** et **zoom de l'écran** sur les valeurs par défaut (Paramètres › Affichage) ;
   - **Ne pas déranger** pendant la présentation.

## 2. Installer le portail

1. Ouvrir Chrome et saisir : **https://xavierlepallabre-cmyk.github.io/portail-tiin/**
2. Attendre l'affichage complet de l'accueil.
3. Menu **⋮** (en haut à droite) › **Ajouter à l'écran d'accueil** › **Installer**.
   Selon la version de Chrome, le libellé peut être **Installer l'application**.
4. Valider. L'icône **Portail TIIN** (barres orange sur fond bleu) apparaît sur l'écran d'accueil ou dans le tiroir d'applications : la faire glisser à l'endroit voulu.
5. Fermer Chrome, puis lancer le portail **depuis l'icône** : il s'ouvre en plein écran, sans barre d'adresse.

## 3. Préparer les applications

1. Depuis le portail, ouvrir **Nucléa TIIN**, attendre le chargement complet, puis revenir avec le bouton **Retour** d'Android.
2. Faire de même avec **Sûreté & Cycle TIIN** et, si possible, ouvrir une fois chacun de ses parcours.

Ce premier passage avec connexion permet à chaque application de garder une copie sur la tablette. Leur fonctionnement hors connexion dépend d'elles, pas du portail : le portail affiche un avertissement si l'on tente de les ouvrir sans réseau.

**Recommandation** : sur la tablette de démonstration, ne pas installer Nucléa TIIN et Sûreté & Cycle TIIN comme applications séparées. Selon la version d'Android, un lien depuis le portail pourrait alors s'ouvrir dans leur propre fenêtre plutôt que dans le portail. Si elles sont déjà installées, vérifier le comportement (voir la procédure de vérification).

## 4. Se déplacer dans le portail

- **Accueil** : bouton en bas (portrait) ou à gauche (paysage), ou l'icône du portail en haut à gauche.
- **Retour** : le bouton Retour d'Android (ou le geste de retour) revient à l'écran précédent, y compris depuis une application ouverte depuis le portail.
- **Thème sombre** : l'icône lune en haut à droite (utile au vidéoprojecteur). Le portail suit sinon le réglage de la tablette.
- **Le dispositif** : l'icône ⓘ en haut à droite présente le projet et son avancement.

## 5. Mettre à jour

Rien à faire : à chaque lancement avec connexion, le portail relit le catalogue. Si une nouvelle version du portail lui-même est publiée, un bandeau **« Mettre à jour »** apparaît en bas de l'écran.

## 6. Désinstaller

Appui long sur l'icône › **Désinstaller**. Aucune donnée personnelle n'est stockée.

## Déploiement sur les 12 tablettes

Répéter les étapes 2 et 3 sur chaque tablette (environ 3 minutes par appareil). Avec une solution de gestion de flotte (MDM, par exemple Samsung Knox ou la solution de la région), l'adresse peut être poussée comme application web sur toutes les tablettes : transmettre l'adresse du portail au service informatique.
